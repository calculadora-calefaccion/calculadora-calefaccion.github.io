# Calculadora de calefacción

Web hermana de [CalorBrasa](https://calorbrasa.github.io/): calcula cuánto cuesta calentar una casa
con estufas de pellets, leña, butano o eléctricas, y cuánto se ahorra dejando el gasóleo.

- Publicada en GitHub Pages: https://calculadora-calefaccion.github.io/
- Todo está en `index.html` (HTML, CSS y JS en un solo archivo).
- Lee el catálogo en vivo de `https://calorbrasa.github.io/data/products.json` (con copia de respaldo dentro de la página).
- Precios de energía por defecto: constante `DEF` en `index.html`. Revisarlos cada mes (el butano cambia cada 2 meses).
- Enlaces a otras webs hermanas: constante `WEBS` en `index.html`.
